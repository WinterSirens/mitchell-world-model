# Impeccable — Frontend Design with Claude Code

## Core idea
Impeccable is a Claude Code design skill/repo that gives the agent a stronger design vocabulary: typography, color, spacing, responsiveness, interaction, motion, UX writing, and anti-pattern detection. Use it when Claude Code can build the page but the visual result risks looking generic or "AI slop."

## When to use it
- Building the AI SHIFT landing page.
- Helping Dad with a website refresh.
- Auditing an existing site before redesigning it.
- Generating several design directions before committing to one.

## Practical workflow
1. Install Impeccable in the project when frontend visual quality matters.
2. Start greenfield work with the craft/planning flow so it asks product, audience, CTA, scope, voice, and visual direction questions.
3. Ask for **macro variants** before component work: "Create three substantially different layouts, show them side by side, and let me open each full screen."
4. Pick the strongest macro direction before tweaking details.
5. Use Live mode for **micro variants** on components: make a section bolder, quieter, clearer, more polished, or more delightful.
6. Run critique/audit/document flows on existing sites before asking for changes.
7. Use polish/harden near the end for final design-system and edge-case passes.

## Durable prompt pattern
For any AI design tool, not just Impeccable:
> "Do not give me one design. Give me three meaningfully different macro directions. Show them side by side, let me open each full screen, and explain the tradeoff each direction makes."

## Cautions
- Do not outsource taste blindly. Treat critiques as useful pressure, not truth.
- Mood boards alone may underperform unless paired with clear product/audience/CTA context.
- Live mode may be rough around the edges; keep changes reviewable.
