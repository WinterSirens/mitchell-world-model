## The SHIFT Method (what we teach)

| Step | What it does | Why it matters |
|------|-----------|---------------|
| **S — Specify** | Define the output before you involve AI | Most AI failures start here: people haven't decided what they want |
| **H — Harvest** | Gather examples, style rules, constraints, source material | Stops AI from producing generic output that sounds like everyone else |
| **I — Inspect** | Map failure modes and build 3–5 test inputs | Know where it breaks *before* you're in front of a client |
| **F — Feed** | Run the workflow on real inputs, see what breaks, refine | Not prompting until it works — testing until it works |
| **T — Telemetry** | Set metrics and a 7-day improvement plan | The handoff keeps getting better instead of sitting in a folder |

We also preview the **6-Gear System** lightly at the end (Manual → Autonomous with monitoring) so participants see where this goes — but we don't sell the full course.
