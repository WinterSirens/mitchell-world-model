# Situation: New Opportunity

## Purpose
Capture how to think about and decide on new opportunities (tools, projects, partnerships, events, etc.) so I do not confuse excitement with strategic value.

## Typical triggers
- New AI tool or framework I want to explore
- Collaboration or partnership invite
- Potential client, course idea, or side project
- Event, meetup, or conference invitation

## Default risks
- Treating novelty as progress
- Overcommitting when commitments are already high
- Diluting focus from the current bottleneck

## Questions to ask
- Does this directly improve my current bottleneck?
- What important work will be delayed or dropped if I say yes?
- Is this compounding (builds on existing assets) or parallel (creates a new track)?
- Would I still want this if I had to give up something concrete to do it?
- Would I still want this in 72 hours?

## Recommended default response
- **Step 0: Sit on it for 24 hours.** No evaluation, no research, no discussion. Let the initial excitement fade. After 24 hours: if you're no longer excited, the answer is no — stop here. If the pull is still there, proceed to the questions below.
- If it does not help the current bottleneck, default to "no for now".
- If commitments are already high, require an explicit tradeoff to say yes.
- If it seems promising but unclear, choose WAIT and schedule a short evaluation block (e.g., 30–60 minutes) instead of an open-ended commitment.

## Agent behavior
When Mitchell mentions a new opportunity, the agent must:
1. Immediately call out the sit-on-it rule: "This is a new opportunity. The rule is to sit on it for 24 hours before any evaluation."
2. Do not analyze the opportunity until the 24-hour period has passed or Mitchell explicitly overrides the rule.
3. If Mitchell wants to discuss it anyway, flag that the conversation is happening inside the cooling period and the rule says no analysis yet.

## When to override the default
- The opportunity is rare and meaningfully aligned with long-term goals.
- It unlocks leverage (distribution, capital, reputation, or learning) that is hard to get otherwise.
- It clearly replaces a lower-value activity rather than stacking on top.
